# AstraPark – Parking Management Android App

## 📱 Giới thiệu

**AstraPark** là ứng dụng Android hỗ trợ quản lý bãi đỗ xe, được xây dựng bằng **Java** trên Android Studio.

Ứng dụng hỗ trợ quản lý thông tin xe, vị trí đỗ, lịch sử ra vào, thanh toán và theo dõi trạng thái bãi đỗ.

## ✨ Chức năng chính

* 🔐 Đăng nhập và quản lý tài khoản
* 🚗 Quản lý xe vào / xe ra
* 🅿️ Quản lý vị trí đỗ xe
* 📋 Theo dõi xe đang đỗ
* 🔎 Tìm kiếm thông tin xe
* 📊 Thống kê dữ liệu bãi đỗ
* 🕒 Xem lịch sử xe ra vào
* 💰 Quản lý thanh toán
* ⚙️ Cấu hình thông tin hệ thống
* ☁️ Tích hợp Firebase Realtime Database

## 🛠️ Công nghệ sử dụng

* **Java**
* **Android Studio**
* **XML**
* **RecyclerView**
* **SQLite**
* **Firebase Realtime Database**
* **Material Design**

## 🚀 Cài đặt

### Yêu cầu

* Android Studio
* JDK
* Android SDK

### Các bước

```bash
git clone https://github.com/ph557787-cell/AstraPark.git
```

Mở project bằng Android Studio và thực hiện **Sync Project with Gradle Files**.

> Lưu ý: File `google-services.json` không được đưa lên repository vì lý do bảo mật. Khi chạy các chức năng Firebase, cần cấu hình Firebase riêng cho môi trường phát triển.
